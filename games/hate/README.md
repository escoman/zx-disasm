# H.A.T.E. (Hostile All-Terrain Encounter) — разбор

**Игра:** Vortex Software, 1989, ZX Spectrum 48K (freeware от автора).
**Цель разбора:** исходный уровень понимания для порта на Вектор-06Ц (КР580ВМ80А).
**Инструмент:** SkoolKit 10.1 (`../../skoolkit/`) + собственные headless-трассировщики.

## Что разобрано и сделано

### 1. Методика и покрытие кода
- Загрузка `HATE.TAP` → базовые снапшоты; исполняемое покрытие собиралось
  прогонами в эмуляторе SkoolKit (C-симулятор) с инжекцией клавиш по
  пофреймовым сценариям (`coverage.py` + `data/scripts/*.txt`).
- 5+ разнообразных прогонов (~150k кадров: миссия, смерть, DEMO-автопилот,
  ABORT-окно, attract) → **сходимость покрытия**: финальные итерации дали
  лишь +10 адресов. Итог: `data/merged_exec.map` (4880 адресов, 4394 в RAM).
- Идентификация состояний игры — хэшем только исполняемого кода движка
  (устойчиво к изменениям backbuffer/данных).

### 2. Архитектура игры (дизассемблирование выполнено полностью, 2 базы)
- **Постоянный движок** $CF32–$F2DF (персистентен всю игру) — база
  `run10_56000.z80` → `data/HATE_engine*.skool`, `asm/HATE_engine.asm` (~10k строк).
- **Титульная/загрузочная база** ($5B8C декомпрессор, $8000-…) — база
  `HATE_ready.z80` → `data/HATE_title*.skool`, `asm/HATE_title.asm` (~6.6k строк).
- Экран $4000–$5AFF, backbuffer $8400–$BFFF, переменные $C000–$CF31.

### 3. Семантика, установленная однозначно
- **Ввод:** $E6FF, режим по $C28F: 0=KEYBOARD, 1=SINCLAIR, 2=KEMPSTON, 3=PROTEK
  (биты портов $F7/$DF/$BF/$FD, строки клавиш расшифрованы).
- **Меню SELECT:** 1–4 = режимы ввода, 5 = DEMO, 6 = START GAME (+гейт SPACE $F1D1).
- **Секреты в миссии:** `p` (без ENTER) = окно ABORT! (ветка $D0BA, подтверждение
  ENTER в цикле $D0D8 → GAME OVER); `u+g` = DEMO-режим ($D089→$D099, $F0DB=$FF,
  автопилот, зелёный рельеф). Подтверждено скриншотами.
- **Строковый банк** $F0E4–$F1A4 (ASCII): ' DEMO ', 'PAUSE!', 'ABORT!', 'SELECT',
  '1 KEYBOARD'…'6 START GAME'.
- **Оконный движок** $EE17 (структуры окон $F0EB/$F12C…, бит 7 кода = разрыв
  строки, $FF = конец).

### 4. Графика (см. также `data/gfx/GFX_NOTES.md`)
- **Векторный (wireframe) конвейер, спрайт-шитов нет**: 3D-проекция каждый кадр
  пишет таблицу сегментов в $C9FE (область переменных); растеризатор $D105–$D150
  рисует сегменты как арифметическую прогрессию адресов (наклонные линии,
  ink-биты из $E0); рельеф процедурный через строковый буфер $6000 и backbuffer.
- Самолёт/танки/враги — 3D-модели (каркас), силуэты меняются с ракурсом.
- **Подробный разбор конвейера — в `ENGINE.MD`** (там же поправки: рендер не векторный,
  а тайловый на клетках 8×8 через кольцевой буфер `$8000–$BFFF`; картинки — в `render/`).
- **Шрифт $6300**: 96 глифов × 8×8, MSB-первый — извлечён
  (`data/gfx/font_6300.bin` + лист `font_6300.png`).
- **HUD**: узкие вертикальные полосы приборов, blit `AND (HL)` ($DECB–$DF05),
  записи через буфер $DD66.
- **Статичный банк геометрии $653A–$8008** (6863 байта, инвариантен между
  далёкими кадрами миссии) — дамп `data/gfx/bank_653A.bin`.
- **Упаковка TAP:** блок 6 = INXS-крауншер + собственный байт-RLE движка
  ($5B8C: escape $97, обратная развёртка $E9F6↓→$FFFF↓) — формат декодирован,
  RLE воспроизведён в Python (35428→41091 Б).

## Как воспроизвести (из корня `skoolkit/`)
```bash
# skool из ctl + снапшота (базы лежат в games/hate/tmp/):
PYTHONPATH=. python3 sna2skool.py -H -C -c ../games/hate/data/HATE_engine.ctl \
    ../games/hate/tmp/run10_56000.z80 > ../games/hate/data/HATE_engine_final.skool
# ASM — ОБЯЗАТЕЛЬНО -F (у sna2skool-вывода нет @start/@end):
PYTHONPATH=. python3 skool2asm.py -q -F -H -c ../games/hate/data/HATE_engine_final.skool \
    > ../games/hate/asm/HATE_engine.asm
# HTML (web-варианты skool — БЕЗ -C, иначе #R-макросы фатально падают):
PYTHONPATH=. python3 skool2html.py -q -d ../games/hate/html ../games/hate/data/HATE_engine_web.skool
```
Проганы покрытия: `python3 ../games/hate/coverage.py <script> <out-prefix> --tstates N`
(запускать из корня skoolkit; пути внутри скриптов вида `hate/data/...` исторически
резолвятся от рабочего каталога — при переносе поправить на `games/hate/...`
или сделать симлинк `hate -> games/hate`).

## Известные ограничения / незакрытые хвосты
- **Завершение миссии** (зачёт, таблица рекордов) скриптами не достигнуто —
  слепые прогоны не умеют прицельно бомбить; по покрытию скрытого кода там нет.
- Формат рёбер/вершин в банке $653A до конца не распарсен (растеризатор и
  формат таблицы сегментов — распарсаны; для порта банк всё равно переписывается).
- Чекпоинты `.z80` фиксируются на границе кадра, часто **посреди POP-блиттера**
  $D378 (стек = данные) — возобновление с инт-таймингом может испортить стек;
  для захвата выбирать снапшоты с PC вне $D378–$D4E9 (например, br1_41000).
- SkoolKit не читает `.dsk` — использован `.tap`-вариант дистрибутива.
