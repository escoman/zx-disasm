# H.A.T.E. — движение юнитов пользователя

## Самолёт (вид 0) и танк (вид 1)

Игрок управляет техникой вида 0 (самолёт, база `$6580`) или вида 1 (танк, база `$67F6`).
Выбор делает дескриптор сцены `$CF04` (10 записей по 4 байта): байт вида чередуется
`00,01,00,01,…` — половина сцен воздушные, половина наземные.

Запись игрока всегда `$C000` (индекс 0). Камера следует за ней, поэтому техника игрока
стоит в одной и той же точке экрана от прохода к проходу.

## Управление

### Самолёт (вид 0)

Клавиатура читается в `$E710`–`$E750`, результат в `$C290` (5 бит управления):

| Клавиша | Порт/строка | Бит | Действие |
|---------|-------------|-----|----------|
| SPACE   | `$7EFE` бит 0 | `$C290` bit 4 | Стрельба |
| T       | `$FEFE` бит 0 | `$C290` bit 3 | Смещение вдаль (вверх-влево, уменьшает `$C2F6`) |
| G       | `$FDFE` бит 0 | `$C290` bit 2 | Смещение ближе (вниз-вправо, увеличивает `$C2F6`) |
| H       | `$BFFE` бит 0 | `$C290` bit 1 | Влево-вверх (уменьшает `$C003`) |
| J       | `$BFFE` бит 1 | `$C290` bit 0 | Вправо-вниз (увеличивает `$C003`) |

Боковое смещение `$C003` **автоматически осциллирует** 0↔44 с шагом ±2 за кадр
(код `$E6AD`–`$E6BC`). Игрок не управляет напрямую — самолёт летит по синусоиде.

### Танк (вид 1)

Танк использует **Kempston джойстик** (порт `$1F`) или цифровые клавиши 1–5, 0–6
(код `$E756`–`$E773`). Маппинг аналогичен самолёту, но боковое смещение
**управляется вручную** через `$C290` bit 0 (клавиша 5 или джойстик вправо).

## Движение вперёд

Камера движется вперёд автоматически. Расстояние камеры `$D14D` увеличивается на **2 за кадр**:

```
$D3F9 LD HL,($D14D)    ; загрузить расстояние
$D3FC INC HL            ; +1
$D3FD INC HL            ; +1
$D3FE LD ($D14D),HL    ; сохранить
```

Скорость: **2 клетки/кадр** = 120 клеток/сек (при 50 FPS).

## Проекция и движение

Движение юнитов обрабатывается в `$EFA5` (проекция):

```
$EFA5 LD IX,$C000              ; запись игрока
...
$EFDC LD L,(IX+$01) / LD H,(IX+$02)  ; расстояние до объекта
$EFE2 LD BC,($D14D)            ; пройденное расстояние камеры
$EFE7 SBC HL,BC                ; относительное расстояние
...
$F010 LD (IX+$0B),L            ; полоса (band) = расстояние в клетках
$F022 LD (IX+$09),A            ; фаза ракурса 0..3
$F02D LD (IX+$0A),A            ; X на экране
```

Поля записи игрока `$C000`:
- `+0` тип (бит 7 = свободна, бит 6 = особый маршрут, бит 5 = уничтожен, младшие 4 бита = номер формы)
- `+1,+2` расстояние до объекта (16 бит)
- `+3` боковое смещение относительно оси дороги
- `+4` клиренс/высота
- `+8` индекс арта: `HL = слово по адресу $C300 + [8]`
- `+9` фаза ракурса 0…3
- `+10` X на экране
- `+11` полоса/строка

## Высота/клиренс (`$C2F6`)

Для самолёта высота управляется клавишами T/G:

```
$E8C2 BIT 2,B          ; клавиша G (смещение ближе/вниз-вправо)
$E8C6 LD A,($E687)     ; счётчик
$E8CD INC A            ; увеличить
$E8CE LD ($E687),A     ; сохранить
$E8D4 ADD A,L          ; прибавить к высоте
$E8DB LD ($C2F6),A     ; сохранить новую высоту

$E8E0 BIT 3,B          ; клавиша T (смещение вдаль/вверх-влево)
$E8E4 LD A,($E688)     ; счётчик
$E8EB INC A            ; увеличить
$E8EC LD ($E688),A     ; сохранить
$E8F4 SUB C            ; вычесть из высоты
$E8FF LD ($C2F6),A     ; сохранить новую высоту
```

Диапазон высоты `$C2F6`: **0–26** (ограничение `$E8D5 CP $1B`).

## Боковое смещение (`$C003`)

Управляется клавишами J/H:

```
$E9D3 BIT 0,B          ; клавиша J (вправо-вниз)
$E9DE INC A            ; увеличить счётчик
$E9EA ADD A,C          ; прибавить к смещению
$E9F0 LD ($C003),A     ; сохранить

$E9F4 BIT 1,B          ; клавиша H (влево-вверх)
$E9FF INC A            ; увеличить счётчик
$EA0B SUB C            ; вычесть из смещения
$EA15 LD ($C003),A     ; сохранить
```

Диапазон бокового смещения `$C003`: **0–70** (ограничение `$E9EB CP E` где E=$47).

## Тень самолёта

Тень рисуется **как часть спрайта** в банке артов `$653A–$8008`. Это не отдельный
элемент рендеринга — чёрное пятно под самолётом закодировано в тех же парах
(AND-маска, OR-значение), что и сам самолёт.

На скриншоте `render/30_unit_player.png` видно:
- **sprite** (верхний левый): самолёт без фона
- **screen** (верхний правый): самолёт на рельефе + чёрная тень внизу
- **mask/value** (нижний левый): маска и значение спрайта
- **model** (нижний правый): реконструкция из модели

Тень — это просто пиксели с AND-маской `$FF` (непрозрачные) и OR-значением `$00`
(чёрный цвет), расположенные в нижней части спрайта.

## Сводная таблица параметров

| Параметр | Самолёт (вид 0) | Танк (вид 1) |
|----------|-----------------|---------------|
| База арта | `$6580` | `$67F6` |
| Скорость вперёд | 2 клетки/кадр | 2 клетки/кадр |
| Боковое смещение | Авто 0↔44 (±2/кадр) + ручное J/H | Ручное управление |
| Высота | 0–26 (T/G) | 0–26 (аналогично) |
| Стрельба | SPACE | Джойстик fire / клавиша 1 |
| Тень | Часть спрайта | Нет (танк на земле) |

## Что известно из ENGINE.MD

- Юниты рисуются через кольцевой буфер `$8000–$BFFF`
- Шаг столбца в кольце `$1FC` (+2 страницы, −4 байта)
- Фаза ракурса 0…3 выбирается проекцией: `((X − боковое) >> 1) & 3`
- При уничтожении (бит 5 типа) класс подменяется на `$03` (анимация гибели)

## Код управления (для справки)

```
; Самолёт: чтение клавиш в $E710-$E750
$E713 LD A,$FB / IN A,($FE)   ; Q-W-E-R-T
$E717 RRA                      ; бит 0 = клавиша T
$E71A BIT 0,(HL)               ; HL=$C000, проверка типа (0=самолёт)
$E71C JR Z,$E722               ; если самолёт
$E71E SET 3,B                  ; T → bit 3 (смещение вдаль/вверх-влево)
$E722 SET 2,B                  ; (для танка)

$E724 LD A,$FD / IN A,($FE)   ; A-S-D-F-G
$E728 RRA                      ; бит 0 = клавиша G
$E72B BIT 0,(HL)               ; проверка типа
$E72D JR Z,$E733
$E72F SET 2,B                  ; G → bit 2 (смещение ближе/вниз-вправо)
$E733 SET 3,B                  ; (для танка)

$E735 LD A,$BF / IN A,($FE)   ; ENTER-L-K-J-H
$E739 RRA / RRA                ; бит 0 = H, бит 1 = J
$E73B JR C,$E73F               ; если H не нажата
$E73D SET 1,B                  ; H → bit 1 (влево-вверх)
$E73F RRA
$E742 JR C,$E744               ; если J не нажата
$E742 SET 0,B                  ; J → bit 0 (вправо-вниз)

$E744 LD A,$7E / IN A,($FE)   ; SPACE
$E748 CPL / AND $1F            ; бит 0 = SPACE
$E74B JR Z,$E74F
$E74D SET 4,B                  ; SPACE → bit 4 (стрельба)

$E750 LD ($C290),A             ; сохранить состояние управления
```
