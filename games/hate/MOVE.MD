# H.A.T.E. — движение юнитов пользователя

## Самолёт (вид 0) и танк (вид 1)

Игрок управляет техникой вида 0 (самолёт, база `$6580`) или вида 1 (танк, база `$67F6`).
Выбор делает дескриптор сцены `$CF04` (10 записей по 4 байта): байт вида чередуется
`00,01,00,01,…` — половина сцен воздушные, половина наземные.

Запись игрока всегда `$C000` (индекс 0). Камера следует за ней, поэтому техника игрока
стоит в одной и той же точке экрана от прохода к проходу.

## Управление

Клавиатура читается из порта `$FE` (код `$D08B`–`$D0C9`):

```
$D08B LD A,$DF / IN A,($FE)    ; клавиши P-O-I-U-Y
$D08D BIT 3,A / JR NZ,$D0BA    ; если бит 3 = 0 → действие
$D091 LD A,$FD / IN A,($FE)    ; клавиши A-S-D-F-G
$D095 BIT 4,A / JR NZ,$D0BA    ; если бит 4 = 0 → действие
```

Конкретные соответствия клавиш направлениям требуют трассировки — в коде видны только
проверки битов, без явных комментариев.

## Проекция и движение

Движение юнитов обрабатывается в `$EFA5` (проекция):

```
$EFA5 LD IX,$C000              ; запись игрока
...
$EFDC LD L,(IX+$01) / LD H,(IX+$02)  ; расстояние до объекта
$EFE2 LD BC,($D14D)            ; пройденное расстояние камеры
$EFE7 SBC HL,BC                ; относительное расстояние
...
$F010 LD (IX+$0B),L            ; полоса (band) = расстояние в клетках
$F022 LD (IX+$09),A            ; фаза ракурса 0..3
$F02D LD (IX+$0A),A            ; X на экране
```

Поля записи игрока `$C000`:
- `+0` тип (бит 7 = свободна, бит 6 = особый маршрут, бит 5 = уничтожен, младшие 4 бита = номер формы)
- `+1,+2` расстояние до объекта (16 бит)
- `+3` боковое смещение относительно оси дороги
- `+4` клиренс/высота
- `+8` индекс арта: `HL = слово по адресу $C300 + [8]`
- `+9` фаза ракурса 0…3
- `+10` X на экране
- `+11` полоса/строка

## Тень самолёта

Тень рисуется **как часть спрайта** в банке артов `$653A–$8008`. Это не отдельный
элемент рендеринга — чёрное пятно под самолётом закодировано в тех же парах
(AND-маска, OR-значение), что и сам самолёт.

На скриншоте `render/30_unit_player.png` видно:
- **sprite** (верхний левый): самолёт без фона
- **screen** (верхний правый): самолёт на рельефе + чёрная тень внизу
- **mask/value** (нижний левый): маска и значение спрайта
- **model** (нижний правый): реконструкция из модели

Тень — это просто пиксели с AND-маской `$FF` (непрозрачные) и OR-значением `$00`
(чёрный цвет), расположенные в нижней части спрайта.

## Диапазоны движения

Требует дополнительного исследования:
- Максимальное смещение по X (боковое движение)
- Ограничения по расстоянию (вперёд/назад)
- Скорость движения в клетках/кадр

## Что известно из ENGINE.MD

- Юниты рисуются через кольцевой буфер `$8000–$BFFF`
- Шаг столбца в кольце `$1FC` (+2 страницы, −4 байта)
- Фаза ракурса 0…3 выбирается проекцией: `((X − боковое) >> 1) & 3`
- При уничтожении (бит 5 типа) класс подменяется на `$03` (анимация гибели)

## Требуется исследование

1. **Точное соответствие клавиш направлениям** — трассировка ввода
2. **Скорость движения** — как быстро меняется расстояние/боковое смещение
3. **Границы движения** — что происходит при достижении края экрана
4. **Различия самолёта и танка** — есть ли разница в управлении/скорости
