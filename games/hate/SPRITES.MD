# H.A.T.E. — как получить спрайты юнитов

Все спрайты юнитов хранятся в банке `$653A–$8008` (6863 байта) и рисуются через
кольцевой буфер `$8000–$BFFF`. Отдельных битмап-картинок нет: каждый юнит — это
набор столбцов из пар (AND-маска, OR-значение), которые кладутся в кольцо с шагом
`+$1FC` и тем же блиттером выводятся на экран.

## Быстрый путь: каталог всех видов

```bash
# 1. Сделать дамп страницы $4000-$7FFF на границе кадра (здесь живёт банк артов).
python3 tools/bankdump.py data/scripts/br5_demo.txt 2000 tmp/bank.bin

# 2. Нарисовать все 16 видов + анимацию гибели в цвете.
python3 tools/kinds.py tmp/bank.bin render/35_unit_kinds.png --colour --sweep

# 3. То же, но монохром и с пометкой «рисовался ли вид в геймплее».
python3 tools/kinds.py tmp/bank.bin render/36_unit_kinds_mono.png --all --sweep tmp/sweep_gp.json

# 4. Только игрок (виды 0 и 1), 4 ракурса.
python3 tools/kinds.py tmp/bank.bin render/34_player_forms.png --only 0,1 --colour
```

`kinds.py` читает таблицу `$C300` (указатели на формы) и для каждого из 23 индексов
(16 видов + 7 кадров гибели) восстанавливает все 4 ракурса. Флаг `--colour` берёт
реальные чернила/бумагу из атрибутов; без него — белый по чёрному.

## Один конкретный спрайт на экране

```bash
# 1. Захватить проход объектов на нужном кадре (сохранит дамп банка рядом).
python3 tools/units.py tmp/probe_play.txt 2000 tmp/units.json --frames 4 --bank

# 2. Посмотреть список юнитов, которые рисуются в проходе.
python3 tools/unit_shot.py tmp/units.json 0
#   pass 0, element 0: class=00 cols=4 ring=9B74 ptr=6580  (игрок-самолёт)
#   pass 0, element 1: class=08 cols=3 ring=A048 ptr=7878  (враг-птица)

# 3. Нарисовать один элемент: 4 панели (спрайт / экран / маска-значение / модель).
python3 tools/unit_shot.py tmp/units.json 0 0 tmp/player.png --bank tmp/units_f2004.bin
```

`unit_shot.py` строит изображение точно так же, как это делает движок: читает столбцы
формы из банка, кладёт их в кольцо по адресу из элемента, потом разворачивает кольцо
в экран. Флаг `--bank` указывает дамп страницы — без него инструмент попытается
угадать банк из самого захвата.

## Вид игрока: самолёт или танк

Дескриптор сцены `$CF04` (10 записей по 4 байта) содержит байт вида техники: `00` =
самолёт (база `$6580`), `01` = танк (база `$67F6`). Половина сцен — воздушные,
половина — наземные.

```bash
# Принудительно рисуем танк: записываем kind=1 в захват.
python3 tools/units.py tmp/probe_play.txt 2000 tmp/units_tank.json --frames 4 --bank --kind 1

# Сверяем побайтово с реальным экраном (84/84 совпадения).
python3 tools/unit_shot.py tmp/units_tank.json 0 0 tmp/tank.png --bank tmp/units_tank_f2004.bin
```

## Плёнка анимации

```bash
# Снимает все спрайты, которые движок рисует за долгий прогон, и выстраивает
# их в ряды по кадрам — видна анимация гибели и вращения.
python3 tools/unitsweep.py data/scripts/br5_demo.txt 1400 12000 tmp/sweep.json --png tmp/sweep.png

# Фильм-стрип по одному указателю (здесь — анимация гибели $7C10/$7CB8).
python3 tools/sprite_strip.py tmp/units.json tmp/death_strip.png --ptr 7C10,7CB8 --scale 3
```

| 12   | $7AA4 | 182 Б  | мелкий снаряд (штрих)            | 2 × 13          |
| 13   | $7B5A | 182 Б  | мелкий снаряд (шар)              | 2 × 13          |
| 14   | $6F58 | 420 Б  | не рисуется в `$FF00`            | —               |

| 16–22| $7C10 | 6×168  | анимация гибели (7 кадров)       | 4 × 21          |

Класс элемента определяет геометрию: `< 4` → 4 ряда × 21 байт, `< $0B` → 3 × 17,
иначе → 2 × 13. Шаг фазы = `2 × рядов × ширину` = `$A8` / `$66` / `$34`.

## Формат формы в банке

Форма = `count` столбцов по `width` пар байт (AND-маска, OR-значение). Столбцы
идут подряд, шаг столбца `2 × width`. Нулевой ряд банка = **нижний** ряд спрайта.

Столбцы кладутся в кольцо с шагом `$1FC` (+2 страницы, −4 байта), что компенсирует
наклон блиттера — поэтому на экране спрайт стоит вертикально.

```
ptr → [AND₀ OR₀] [AND₁ OR₁] ... [AND_{w-1} OR_{w-1}]   ← столбец 0
      [AND_w OR_w] ...                                    ← столбец 1
      ...
```
