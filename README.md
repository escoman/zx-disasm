# zx-disasm — разбор игр ZX Spectrum

Рабочий репозиторий реверс-инжиниринга игр ZX Spectrum: от TAP/снапшотов
до полных дизассемблирований с восстановленной семантикой кода и данных.
Основная цель разборов — портирование игр на другие платформы
(в частности, Вектор-06Ц / КР580ВМ80А).

## Инструмент

Разбор строится на **[SkoolKit 10.1](skoolkit/)** (Python-набор инструментов
реверс-инжиниринга Richard Dymond'а: `sna2skool`, `skool2asm`, `skool2html`,
`tap2sna`, эмулятор-симулятор с трассировкой) плюс собственные скрипты
покрытия и захвата, расположенные в папке каждой игры.

## Структура репозитория

```
zx-disasm/
├── skoolkit/          — SkoolKit 10.1 (инструмент; без изменений апстрима)
├── games/             — разбираемые игры, по папке на игру
│   └── hate/          — H.A.T.E. (Vortex Software, 1989) — разбор завершён
│       ├── README.md  — состояние разбора: что сделано, как воспроизвести
│       ├── orig/      — оригинал игры (дистрибутив + распакованные файлы)
│       ├── coverage.py, stream_capture.py   — скрипты трассировки/захвата
│       ├── data/      — результаты: .skool/.ctl, exec-карты, сценарии
│       │   └── gfx/   — извлечённая графика (шрифт, банк геометрии, заметки)
│       ├── asm/       — ASM-листинги (Zeus-синтаксис, с метками)
│       ├── html/      — браузерные листинги (skool2html)
│       └── tmp/       — отладочные артефакты: снапшоты-базы, чекпоинты, PNG
└── README.md
```

### Конвенции папки игры (`games/<name>/`)

| Подпапка | Назначение |
|---|---|
| `orig/`  | Оригиналы дистрибутивов: zip-архивы игр и их распакованное содержимое (TAP/DSK/SNA/Z80, SCR, POKES, тексты издателя). Хранить без изменений; распаковывать здесь же, чтобы не разархивировать каждый раз |
| `data/`  | Итоговые артефакты: `.skool`-файлы, `.ctl`-конфигурации, карты покрытия, сценарии ввода (`data/scripts/`), извлечённые ассеты (`data/gfx/`), рабочие копии оригиналов (TAP/SCR/POKES) |
| `asm/`   | Дизассемблированные листинги в ассемблерном синтаксисе |
| `html/`  | Просматриваемые в браузере листинги с перекрёстными ссылками |
| `tmp/`   | Отладочное: базовые снапшоты `.z80`, чекпоинты прогонов, скриншоты, exec-карты — не является результатом, но нужен для воспроизведения |
| `README.md` | Обязателен: методика, установленная семантика, артефакты, команды воспроизведения, известные ограничения |

## Методика разбора (кратко)

1. Загрузка оригинала (`tap2sna`/эмуляция) → базовые снапшоты состояний игры.
2. Headless-прогоны в симуляторе SkoolKit с инжекцией клавиш по пофреймовым
   сценариям → карта исполненных адресов; итерации до сходимости покрытия.
3. Классификация код/данные по exec-карте → `.ctl` → `.skool` (sna2skool).
4. Уточнение семантики: строковые банки, диффы снапшотов, захват подсистем;
   документирование в заголовках `.ctl` и заметках.
5. Генерация выходных артефактов: ASM (`skool2asm -F`), HTML (`skool2html`).

## Примечание о путях

Скрипты разборов исторически резолвят пути вида `hate/data/...` от рабочего
каталога — корня `skoolkit/`. Для запуска из этого репозитория создайте
симлинк в копии skoolkit: `ln -s ../games/hate skoolkit/hate` (или поправьте
пути в скриптах).
